# Python 教务管理系统

这是我在学习 Python 基础阶段完成的一个控制台教务管理系统项目。

项目主要用于练习 Python 面向对象编程、字典、文件读写、JSON 数据持久化、异常处理以及排序等基础知识。

## 功能

目前已实现以下功能：

- 添加学生信息
- 修改学生信息
- 删除学生信息
- 删除全部学生信息
- 查询指定学生信息
- 查看全部学生信息
- 按学生总成绩进行排序
- 学生成绩输入范围验证
- JSON 文件持久化保存学生数据

## 使用技术

- Python
- 面向对象编程 OOP
- 字典 Dictionary
- JSON
- 文件读写
- 异常处理 try / except
- lambda 表达式
- list.sort() 排序

## 项目结构

```text
项目文件夹
├── 教务系统最终版.py
├── 学生信息.json
└── README.md
其中：
- main.py：教务管理系统主程序
- 学生信息.json：用于保存学生成绩信息
- README.md：项目说明文档
数据格式
学生数据以 JSON 格式进行保存，例如：
{
  "张三": {
    "姓名": "张三",
    "语文": 90,
    "数学": 95,
    "英语": 85,
    "总分": 270
  }
}

运行方式
确保电脑已经安装 Python。
然后运行：
python main.py

运行程序后，根据控制台菜单输入对应的功能编号即可。
项目菜单
1. 添加学生信息
2. 修改学生信息
3. 删除学生信息
4. 删除全部学生信息
5. 查询学生信息
6. 查看全部学生信息
7. 按成绩排序
8. 退出教务系统
