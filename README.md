# Python 教务管理系统

这是我在学习 Python 基础阶段完成的一个控制台教务管理系统项目。

项目主要用于练习 Python 面向对象编程、字典、文件读写、JSON 数据持久化、异常处理以及排序等基础知识。

## 功能

目前已实现以下功能：

- 添加学生信息
- 修改学生信息
- 删除学生信息
- 删除全部学生信息
- 查询指定学生信息
- 查看全部学生信息
- 按学生总成绩进行排序
- 学生成绩输入范围验证
- JSON 文件持久化保存学生数据

## 使用技术

- Python
- 面向对象编程 OOP
- 字典 Dictionary
- JSON
- 文件读写
- 异常处理 try / except
- lambda 表达式
- list.sort() 排序
